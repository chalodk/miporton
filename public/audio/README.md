# Audios de ejemplo — mensajes al llamar

Coloca aquí los tres MP3 (mismos nombres) para el demo del sitio:

| Archivo | Ejemplo en UI |
|---|---|
| `mensaje-caminos.mp3` | Condiciones de caminos / mantención |
| `mensaje-festividad.mp3` | Saludo por festividad |
| `mensaje-asamblea.mp3` | Aviso interno (asamblea / comunicado) |

Recomendado: 8–20 s, voz clara, sin nombres ni teléfonos de residentes.
